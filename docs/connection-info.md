# Beitrittsinformationen in der Übersicht

„Mitspielen“ steht direkt unter der Serverkarte. Bei Enshrouded zeigt es die Adresse für denselben PC, verfügbare Windows-Heimnetzadressen und eine mögliche externe Adresse samt konfiguriertem Query-Port. Jede Adresse hat eine Kopierschaltfläche; falls die Zwischenablage nicht verfügbar ist, wird der Text zum manuellen Kopieren markiert. Passwörter werden dort weder geladen noch mitkopiert.

Im Spiel: Online-Spiele → Dedizierter Server → T / Suche nach IPv4 oder Domain. Alternativ die Adresse als Steam-Serverfavorit hinzufügen. Der Hersteller beschreibt [IP und Query-Port für Favoriten](https://enshrouded.zendesk.com/hc/en-us/articles/16454683440541-Favorite-Server-via-IP) und [IPv4, Standard-Query-Port und zusätzliche Steam-Ports](https://enshrouded.zendesk.com/hc/en-us/articles/16056312924957-Dedicated-Server-FAQ). Die Ingame-Taste ist im Nutzerbild der aktuellen Spielversion belegt.

Die öffentliche IPv4 ist **kein Erreichbarkeitstest**. Routerweiterleitung, Windows-Firewall, zusätzliche vom Spiel benötigte Ports und Anschlussart müssen passen. CGNAT/DS-Lite kann eingehendes IPv4 verhindern. Die Anzeige nimmt eine unveränderte externe/interne Portzuordnung an. Bei abweichender Portweiterleitung gilt der tatsächlich eingerichtete externe Port. Im eigenen Heimnetz die Heimnetzadresse verwenden, um eine Abhängigkeit von NAT-Loopback zu vermeiden.

Die Adressermittlung läuft lesend auf dem nativen Windows-Host über `scripts/windows-network.ps1`, nicht auf dem virtuellen WSL-Netzadapter. Alle bevorzugten IPv4-Adressen von Interfaces mit IPv4-Standardroute werden berücksichtigt; bei mehreren Routen können mehrere Kandidaten erscheinen. Die öffentliche Adresse stammt aus einem HTTPS-Aufruf an `api.ipify.org`. Dabei wird keine Spielkonfiguration übertragen. Eine VPN-Route kann eine andere öffentliche Adresse ergeben und ist kein Nachweis einer passenden eingehenden Route.

Der Dienst lädt die Daten beim regulären Managerstart und alle 15 Minuten im Hintergrund. `POST /api/connections/refresh` mit ausdrücklicher Profil-ID und Besitzerberechtigung stößt eine erneute Ermittlung an (202). Gleichzeitige Abfragen werden zusammengefasst, Statuspolls lesen ausschließlich den Speicher. Fehler und abgelaufene Daten entfernen kopierbare Netzwerkadressen; die lokale Adresse bleibt aus der Konfiguration ableitbar. Der PowerShell-Aufruf ist zeitlich begrenzt. Kein persistenter IP-Verlauf, keine Router-/Firewalländerung, keine Spielaktion.

Pro Spiel beschreibt `connection` im Profil den bestätigten Beitrittsweg. Enshrouded verwendet `ip_query` mit `port_key: queryPort` und `bind_key: ip`; eingeschränkte Bindungen begrenzen angebotene Adressen. ASKA und Profile ohne bestätigte direkte IP-Unterstützung verwenden `server_browser`: Servernamen in der Spielserverliste suchen. Kein automatischer Schluss von einem Query-Port auf einen direkten Spielbeitritt.
